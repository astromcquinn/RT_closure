# Figures

Drafts are copies of the report figures of the code repository,
`astromcquinn/NewRadHydroCode`, `docs/figures/` at `main` (2bc8f62). The
final figures are made on klone (outline.md §3, §6). Record the code commit
and the command of each final figure here.

**Late-end suite (2026-11-12).** Figs. 1–4 and `fig_mfp_width` are now made from
the late-end 512³ suite on klone, `/gscratch/astro/mcquinn/radhydro/runs/reion512late*`
(rays, case A + RR, M1, OTVET with the Gnedin & Abel 2001 background
`otvet_background = ga01`, screen, cone; f6 = 0.10, P11, no SN heating; binary
and analysis tools NewRadHydroCode main 6658086). The OTVET run is labelled
"OTVET" in the figures (it was "thin OTVET" 2026-11-13 to 2026-11-15; back to
"OTVET" at the user's request, and drawn wider since the split's dashed curve
follows it before overlap): its background stays inactive
(Λ = 0 until the last per cent of the volume ionises, 2 % of the photons at
z = 5; a run without it, `$R/reion512late_otvet`, agrees to 1e-5 in x_HII and
3 % in P_Γ at z = 4.99). The split's late-end rerun (`$R/reion512late_otvet_split`) finished
2026-11-15 and is in Figs. 2 and 4 and `fig_mfp_width` (data job
`$R/reion512late_figures/paper/split_data.sh`: the same tools on the seven runs; the six
earlier runs' rows are unchanged). The
older `*_draft` files and rows below are from the earlier suite (f6 = 0.11).
`R = /gscratch/astro/mcquinn/radhydro/runs`; the data job is
`$R/reion512late_figures/paper/paper_data.sh`, the map job `maps.sh` beside it.

**The uniform test with the first-cell injection (2026-11-28; not in the paper).** `fig_app_convergence_inject2.{pdf,png}`: the appendix figure with the moment runs redone with `moment_inject = 2` of NewRadHydroCode (PR 46, `docs/rt_moments.md` §10: a substep's source photons spread over their first cell of travel, 0.61 in the source cell). Made by `python3 scripts/fig_app_convergence.py --variants --inject2`; the open symbols at 128³ are the suite's injection (after the transport) and injection before it. Data: `data/convergence/T2_N<N>_l{4,1}.txt` (`moment_transfer N λ 0 {m1,otvet} steps prefix 1 2 4` with steps = 20 λ, at least 400, then `moment_transfer.py`; run in a cloud container, where the same commands with inject 1 and 0 give the paper's `T_N64_l4.txt` digit for digit) and `Tlin2_N<N>_l{4,1}.txt` (`moment_transfer_exact.py N frac 4 --code T2…`: the exact linear solution of the discrete scheme with the three injections, and the code over it, 0.97–1.01 in every bin). 32³, 64³ and 128³ so far; 256³ to follow. The paper's `fig_app_convergence` is unchanged.

**Rays, Screen and Cone capitalised in the figures (2026-11-28, user; as in the text).** The labels of every figure in the paper now read "Rays", "Screen", "Cone" and "Rays, case A + RR"; the axes read P/P_Rays, "r(k) with Rays" and Γ_HI/Γ̄_Rays. The keys of the data files are unchanged (lower case).
- `fig_history`, `fig2_pk_xHII`, `fig4_pk_gamma`, `fig_pdf_width`, `fig_app_convergence`: redrawn from `data/` with their scripts (the labels are `RUNS` of `scripts/fig_pk.py`, and strings in `fig_pdf_width.py` and `fig_app_convergence.py`; the appendix figure with `--variants`, as committed). Before the labels were changed, each script reproduced the committed PNG pixel for pixel.
- `fig1_maps_xHII.png`, `fig3_gamma_maps.png`: the cubes are on klone, so only the column titles (and the colour bar's label of Fig. 3) were redrawn, with the new mode `scripts/fig_maps.py --retitle`: the titles are drawn on empty panels of the same layout and the band above the first row is copied into the existing PNG; every panel pixel is the klone figure's. With the old labels the mode gives back the committed figures exactly (0 pixels differ). Commands: `scripts/fig_maps.py --field xHII --steps 69,84,93 --retitle figures/fig1_maps_xHII.png --out figures/fig1_maps_xHII.png x:Rays x:M1 x:OTVET x:Cone x:21cmFAST` and `scripts/fig_maps.py --field gamma --relative --steps 84,93,99 --retitle figures/fig3_gamma_maps.png --out figures/fig3_gamma_maps.png x:Rays x:M1 x:OTVET x:Screen x:Cone "x:Rays\ncase A + RR"`. A redraw from the cubes should use these labels in the commands of the table below (the `_panels.txt` files carry them already).

- **Fonts.** Draw every figure with matplotlib's default font (DejaVu Sans). `fig2_pk_xHII` and `fig4_pk_gamma` of the k ≤ 10 commit (d22772e) were drawn on a machine whose `/etc/matplotlibrc` selects Inter and so differed from the other figures; they are redrawn here with the default (`MATPLOTLIBRC` pointing to an empty file).

**Power spectra to k = 10 h/Mpc (2026-11-28, user).** `fig2_pk_xHII` and `fig4_pk_gamma` now stop at k = 10 h/Mpc: `scripts/fig_pk.py` drops the bins above `KMAX = 10` (the last one drawn is k = 8.2 h/Mpc; the next is 10.6), so every axis scales to what is shown, and labels the logarithmic axes with plain numbers. The data files are unchanged and still reach beyond the Nyquist frequency (40 h/Mpc); `python3 scripts/fig_pk.py --kmax 0` draws all of it. Not redrawn: `fig2_pk_xHII_early`, the `_oldsuite` pair and the figures of `convergence.tex` (none is in the paper). The text no longer discusses the suite's spectra above that (user, 2026-11-28): the statements that M1 overtakes the rays at k ≳ 15 h/Mpc (kΔx ≈ 1.4) were removed from Section 3.2, the conclusions and the appendix; the appendix still describes the uniform test's own crossing at kΔx ≈ 1.3, which its figure shows.

**The cone without the split blend (2026-11-20).** Every figure and data file with the cone now uses the no-blend cone (`otvet_cone_blend = 0`: the receivers' cone light plus the optically thin near field, no σ = 4 blend with the split tensor), run `$R/reion512late_otvet_conenb` (= `reion512late_otvet_cone` params + `otvet_cone_blend = 0`, binary `$R/rt_late512_bin2`, NewRadHydroCode 6658086; 9.7 h on 192 cores). A 512³ comparison with the blended cone (`$R/reion512late_figures/conenb/`) found the two within a few per cent in x_HII power and history and within ±5 % in Γ power at k ≤ 2 h/Mpc, the no-blend cone having 10–25 % more Γ power at k ≈ 4–10 h/Mpc during reionization and 5–15 % less (closer to the rays) at k ≈ 1–4 after overlap; the label stays `cone`. Its z ≈ 5.695 snapshot is the bit-identical rerun `$R/reion512late_otvet_conenb_z570` (same overrides as the other four, with checkpoints on for ckpt-g2; stats.txt of steps 1–85 and the step-83 cubes identical, compare.py --rtol 0 --atol-frac 0), seen through `$R/paper_view/reion512late_otvet_conenb`. Data job `$R/reion512late_figures/paper_nb/regen_nb.sh` (the commands of paper_view/regen.sh, paper/taueff_box.sh, rt_closure_paper/es_early/early.sh, paper/{taueff_temp,temp_z5}.sh and paper/taueff_pdf.py with only the cone swapped; each file keeps its own snapshot convention). Only the cone's columns, rows and blocks changed in every data file. All figures with the cone were remade with their usual commands.

**Middle row at z = 5.695 (2026-11-19).** The middle row (z ≈ 5.70, x_V = 0.80) of
Figs. 1–4, `data/pdf_gamma.txt` and the z ≈ 5.70 row of `fig_mfp_width` now take OTVET,
split, screen and cone at their hydro step 84 (z = 5.6949, 5.6948, 5.6943, 5.6944;
x_HII,V = 0.818, 0.818, 0.827, 0.814; the rays 0.803 at z = 5.6953) instead of step 83
(z = 5.75), the snapshot their `zdata1 = 5.75` output had fallen on. Step 84 had no cubes
and the restart files were gone, so the four runs were rerun from the start with the same
binary (`$R/rt_late512_bin2/build/radhydro`, NewRadHydroCode 6658086), the original
`params.txt` unchanged and the command-line overrides `fields_every=84 zdata2=5.70
run_steps=85 restart_every=0 movie_dz=0` (fields and `Gas/u_gas` at step 84, stop after
step 85; checked first on a small problem not to change the evolution), into
`$R/<run>_z570` (46 GB each; jobs 43354553, 43357750–52). Each rerun is bit-for-bit the
original: `stats.txt` of all 85 steps identical (the `idata2` output counter aside) and the
step-83 cubes (`fHI`, `fHeI`, `fHeII`, `temp`, `rhog`, `gammaHI`, `gammaHI_avg`) identical
under `tools/compare/compare.py --rtol 0 --atol-frac 0`. The figure tools read the runs
through `$R/paper_view/<run>` (`make_views.sh` there): symlinks to the original run
directory except `step_0084` (the rerun's) and `step_0083` (its `stats.txt` only, so that
`igm_stats.py`, which measures every snapshot with cubes, sees the rays' snapshot set),
and `Gas/` with the rerun's `u_gas.z=05.69xx` added. The data job is
`$R/paper_view/regen.sh` (the commands of `paper_data.sh`, `split_data.sh` and `maps.sh`
on the views, output in `$R/reion512late_figures/paper_z570`; the full `igm_stats` rerun
on the views so that λ_mfp at z = 5.695 is measured, not interpolated). Diffed against
the previous files, only the middle-row blocks and rows of the four runs changed (every
other snapshot's numbers, including λ_mfp, identical); `fig_pk.py` and `fig_mfp_width.py`
rerun on the new data. `data/history.txt` was remade the same way (2026-11-19; `$R/paper_view/history_view.py`, which is
`history.py` reading the four runs from the views; only their z ≈ 5.70 rows changed) and `fig_history`
with it. Not redone: `data/taueff_pdf.txt` and `data/taueff_uniform.txt` (`fig_taueff_pdf`, not in the paper;
the four runs still at z = 5.75 there; `fig_pdf_width` uses only the rays' uniform-Γ width) and
`$R/reion512late_figures/paper/taueff/taueff_width_err.txt` (not used here).
